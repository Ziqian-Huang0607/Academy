**Functions**

- Definition of Function:
- A function is a correspondence or rule that assigns to every element in a set $D$exactly one element in a set $R$.
- The set $D$ is called the domain of the function.
- The set $R$ is called the range.
- A function $f$maps, or pairs, a domain element $x$ to a range element $f(x)$, read "the value of $f$at $x$" or "$f$of $x$".
- Another representation: a set of ordered pairs $(x,y)$ to describe a function $f$, where$x$ is an element of the domain and y is the corresponding element of the range.
- Form: $\{(x,y)|y=f(x)\}$ or $y=f(x)$, other letters can be used for variables.
  - Rule (expression): the formula or mapping rule
  - Domain (if not specified): consists of all real numbers for which the function produces real values.
- Graph of a Function:
- In an xy-plane, the graph of a function= consists of all points $(x,f(x))$.
      - The domain of $y=f(x)$ is the set of the x-coordinates of points on the graph of $f.$ Projecting the graph of$f$ on the x-axis gives a graph of the domain.
      - The range of$y=f(x)$is the set of the y-coordinates of points on the graph of$f$. Projecting the graph of $f$ on the y-axis gives a graph of the range.
      - The zeros of $y=f(x)$ are the x-intercepts of the graph.
- Independent & Dependent Variables
- x and y are called independent and dependent variables, respectively.
- The dependent variable is associated with the vertical axis (the y-axis).
- The independent variable is associated with the horizontal axis (the x-axis).
- Relations and Functions
- Functions are a subset of the more general class of correspondences called relations.
- A relation is any correspondence or rule that pairs the members of two sets (the domain and the range). A relation can be represented as a set of ordered pairs.
- The Vertical‑Line Test
- Rule: If no vertical line intersects a given graph in more than one point, then the graph is the graph of a function.
- Geometry formula (sum of interior angles of an n‑gon)
- A formula from geometry states that $S=\left( n-2 \right)180^\circ$ → this gives the sum of the measures of the interior angles of an n-gon.
- Domain: $n\ge 3$
- Range: $\{s|s=180k,k\in \text{ positiveintegers }\}$
- Greatest Integer Function (Floor Function)
- Definition: The greatest integer function assigns to each number the greatest integer less than or equal to the number.
- Notation: $y=\left\lfloor x \right\rfloor$ ($y=\llbracket x \rrbracket$ or $y=\text{ int }(x)$ in some textbooks)
- Read as the floor of x
- $$\left\lfloor 5.28 \right\rfloor=5,\left\lfloor 5 \right\rfloor=5,\left\lfloor \pi \right\rfloor=3,\left\lfloor -1.7 \right\rfloor=-2$$
- Ceiling Function
- Definition (by contrast): $c(x)=\left\lceil x \right\rceil$is called the ceiling of$x$; it returns the least integer greater than or equal to $x.$
- $\left\lceil 5.28 \right\rceil=6,\left\lceil \pi \right\rceil=4,\left\lceil -1.7 \right\rceil=-1$
- Equal functions:
- Two functions f and g are equal functions if both of these two conditions are satisfied:
      - The domain of f is equal to the domain of g.
      - For all $x$ in the domain, $f\left( x \right)=g(x)$
- Rules to check if functions are identical:
  - Check their domains are exactly the same set
  - Check they produce the same output value for every input x inside the domain
  - If either condition fails → they are not equal functions.
