**Complex Numbers:**

- Number system hierarchy
- Complex numbers: $a+bi$
  - Real numbers ($a$)
    - $a$: real part
    - $$\text{ Rationalnumbers }\supset \text{ integers }\supset \text{ wholenumber }\supset \text{ naturalnumbers }$$
      - Rational number: any number that can be written as $\frac{p}{q}$, where $p,q$ are integers and$q\ne 0$
      - Their decimals are terminating or repeating
      - Integers: Whole positive numbers, zero, and whole negative numbers
      - If it is a positive integer, then do not contain 0
      - Whole numbers: integers start at 0
      - Natural numbers: integers start at 1
    - Irrational numbers: Real numbers that cannot be written as a simple fraction $\frac{p}{q}$
      - Their decimal expansions are non-terminating and non-repeating
  - Imaginary numbers ($bi$)
- Imaginary part of complex numbers
- $b$: coefficient of the imaginary part
- $i$: the imaginary unit
  - $$i=\sqrt{-1}$$
  - $${i}^{2}=-1$$
- If $b=0$, the number has no imaginary part, so it is a real number
- If $b\ne 0$, the number has imaginary part, so it is a complex number
- If $a=0,b\ne 0,bi$ is a pure complex number
- $a+bi=c+di$ if and only if $a=\text{ candb }=d$
- Complex conjugates: $z=a+bi,\overline{z}=a-bi$
- Given two complex numbers $a+bi,c+di$ then:
  - Addition: $(a+bi)+(c+di)=\left( a+c \right)+\left( b+d \right)i$
  - Subtraction: $\left( a+bi \right)-\left( c+di \right)=\left( a-c \right)-(b-d)i$
  - Multiplication: $\left( a+bi \right)\times \left( c+di \right)=ac-bd+(ad+bc)i$
  - Division: $\frac{\left( a+bi \right)}{\left( c+di \right)}=\frac{\left( ac+bd \right)+(bc-ad)i}{{c}^{2}+{d}^{2}}$
- Pattern of squares of $i$
  - $${i}^{n}=x$$
  - $$n\equiv 0\left( \bmod 4 \right)\to x=1$$
  - $$n\equiv 1\left( \bmod 4 \right)\to x=i$$
  - $$n\equiv 2\left( \bmod 4 \right)\to x=-1$$
  - $$n\equiv 3\left( \bmod 4 \right)\to x=-i$$

**Quadratic Equations:**

- Concepts
- Standard form: a quadratic equation in one variable
- $a{x}^{2}+bx+c=0,a\ne 0,\text{ anda },b,c$are real numbers
- Solution/ root: substituting each solution for the variable can make the equation true
- Method 1: Factoring
- Whenever the product of two factors is zero, at least one of the factors must be zero.
- Always the first method to consider.
- Write the quadratic equation in general form $a{x}^{2}+bx+c=0$ first.
- $$m\times n=c,m+n=b\to {x}^{2}+bx+c=(x+m)(x+n)$$
- Method 2: Completing the square:
- One side of an equation can be made into a perfect square trinomial.
- Consider using the method when “b” is an even number.
- Steps: (begin with general form $a{x}^{2}+bx+c=0$)
- Move “c” into the other side: ${x}^{2}+bx=-c$
- Take half of the linear coefficient (b), then square it: ${\left( \frac{b}{2} \right)}^{2}$
- Add it to both sides: ${x}^{2}+bx+{\left( \frac{b}{2} \right)}^{2}=\pm c+{\left( \frac{b}{2} \right)}^{2}$
- Simplify and solve for “x”: ${\left( x+\frac{b}{2} \right)}^{2}=\pm c+{\left( \frac{b}{2} \right)}^{2}$
- Method 3: The Quadratic Formula:

$$x=\frac{-b\pm \sqrt{{b}^{2}-4ac}}{2a},(a\ne 0)$$

- The discriminant ${b}^{2}-4ac$:
- ${b}^{2}-4ac$ > 0 $\to$ the equation has two different real solutions.
- ${b}^{2}-4ac$ = 0 $\to$ the equation has one real solution (double root).
- ${b}^{2}-4ac$ < 0 $\to$ the equation has zero real solutions.
- Special case: losing a root:
- Cannot directly cross out the same part in two sides. Organize the same parts into one side and use distributive property to solve the question.
- Special case: extraneous root:
- When one side of the equation is squared, there will be one more possible answer created, so need to check and eliminate one answer.
- Keep steps of eliminating.
- Make sure to write down the correct answer again after eliminating the wrong one.

**Quadratic Functions:**

- Basic concepts:
- Axis: the graph of a quadratic function has a vertical axis of symmetry.
- $x=\frac{-b}{2a}$ (axis is a vertical line not a numerical value so “x” needs to be included)
- Given vertex form: $x=h$
- Given/calculated x-intercept: $x=\frac{{x}_{1}+{x}_{2}}{2}$
- Vertex: the point where the parabola intersects the axis of symmetry.
- Directly calculate: $\left( \frac{-b}{2a},f\left( \frac{-b}{2a} \right) \right)$
- Given vertex form: $(h,k)$
- Opening:
- If a>0: parabola opens upwards$\to$ vertex is minimum value of function.
- If a<0: parabola opens downward $\to$ vertex is maximum value of function.
- Steepness: the bigger |a| is, the narrower the parabola is.
- Zeros of the function: (x-intercept)
- ${b}^{2}-4ac$ > 0 $\to$ 2 x-intercept
- ${b}^{2}-4ac$ = 0 $\to$ 1 x-intercept (the parabola and x-axis is tangent)
- ${b}^{2}-4ac$ < 0 $\to$ 0 x-intercept
- Forms of Quadratic functions:
- General form: $f\left( x \right)=a{x}^{2}+bx+c$
- Vertex form: $y=a{\left( x-h \right)}^{2}+k$
- the value of “h” is decided by making the value of the parenthesis 0.
- Zero form: $y=a\left( x-{x}_{1} \right)(x-{x}_{2})$
- Graphing Quadratic functions:
- Draw: x-intercept, y-intercept, axis of symmetry (dash line), vertex.
- Label the points (axis of symmetry in form of x = number).
- If there are numbers such as $\sqrt{3}$, adjust the scale of graph $\to$ need exact form
