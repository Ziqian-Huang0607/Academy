### 1. Functions and basic notation

A function matches each input x with exactly one output y. We write y = f(x). To find f(3), replace every x with 3.

**Example:** f(x) = 2x − 5

f(3) = 2(3) − 5 = 1

f(−2) = 2(−2) − 5 = −9

Domain = allowed x-values. Range = possible y-values. The x-intercept happens when y = 0; the y-intercept happens when x = 0.

### 2. Linear functions

**Slope-intercept form:** y = mx + b. m is the slope and b is the y-intercept.

**Slope between two points:** m = (y2 – y1)/(x2 – x1). Positive slope rises left to right; negative slope falls.

**Example:** line through (1, 2) and (3, 8)

m = (8 − 2)/(3 − 1) = 6/2 = 3

**Use y = mx + b:** 2 = 3(1) + b, so b = −1

**Equation:** y = 3x − 1

**Remember:** Parallel lines have the same slope. Perpendicular nonvertical lines have slopes whose product is −1.

### 3. Solving and graphing linear equations

**Keep equations balanced:** whatever you do to one side, do to the other. For graphing, plot the y-intercept first and use rise/run for the slope.

**Example:** 3x − 7 = 11

**Add 7:** 3x = 18

**Divide by 3:** x = 6

### 4. What is a quadratic function?

**Standard form:** f(x) = ax^2 + bx + c, where a ≠ 0. Its graph is a parabola.

If a > 0, it opens up and has a minimum. If a < 0, it opens down and has a maximum.

The axis of symmetry is x = −b/(2a). Plug this x-value into f(x) to get the vertex.

**Example:** f(x) = x^2 − 4x + 3

**Axis:** x = −(−4)/(2 x 1) = 2

**Vertex y-value:** f(2) = 4 − 8 + 3 = −1

Vertex = (2, −1); y-intercept = (0, 3)

### 5. Three useful quadratic forms

**Standard:** ax^2 + bx + c → easy to see the y-intercept c.

**Vertex:** a(x − h)^2 + k → vertex (h, k).

**Factored:** a(x – r1)(x – r2) → zeros r1 and r2.

Same quadratic, different forms

X^2 − 4x + 3 = (x − 1)(x − 3)

X^2 − 4x + 3 = (x − 2)^2 − 1

**Remember:** A vertex at (h, k) means the axis is x = h, not x = −h.

### 6. Factoring and the zero-product rule

First put the equation equal to zero. If AB = 0, then A = 0 or B = 0.

**Example:** x^2 − 5x + 6 = 0

**Factor:** (x − 2)(x − 3) = 0

x = 2 or x = 3

### 7. Square roots and completing the square

**Square root method:** (x − 4)^2 = 9

x − 4 = +-3

x = 7 or x = 1

**Completing the square:** x^2 + 6x + 5 = 0

**Move 5:** x^2 + 6x = −5

**Add (6/2)^2 = 9 to both sides:** (x + 3)^2 = 4

x + 3 = ±2, so x = −1 or −5

### 8. Quadratic formula and discriminant

**For ax^2 + bx + c = 0:** x = (−b ± √(b^2 − 4ac))/(2a).

**Discriminant Delta = b^2** **−** **4ac:** positive : 2 distinct real roots; zero : 1 repeated real root; negative : no real roots.

**Example:** 2x^2 + 3x − 2 = 0

a = 2, b = 3, c = −2; Delta = 9 + 16 = 25

x = (−3 +- 5)/4 ; x = 1/2 or −2

**Remember:** Use +- when taking a square root. And put the ENTIRE numerator over 2a.

### 9. Sketching a parabola

**A good sketch includes:** opening direction, vertex, axis of symmetry, x-intercepts (if any), and y-intercept.

**Example:** y = −x^2 + 4x − 3

a = −1, so opens down

**Axis:** x = −4/(2 x −1) = 2; vertex: (2, 1)

**Zeros:** −(x − 1)(x − 3) = 0 ; x = 1, 3

**y-intercept:** (0, −3). Plot these points, then sketch.

### 10. Transformations

**Start with y = x^2. In y = a(x** **−** **h)^2 + k:** h moves right/left, k moves up/down, and a controls reflection and width.

For example, y = −2(x − 3)^2 + 1 shifts right 3, up 1, reflects downward, and is narrower than y = x^2.

### 11. Maximum and minimum problems

The vertex gives the maximum or minimum output. If the problem asks for when an object hits the ground, solve height = 0 instead.

**Example:** h(t) = −t^2 + 6t + 2

Maximum occurs at t = −6/(2 x −1) = 3

h(3) = −9 + 18 + 2 = 11

Maximum height is 11 units at t = 3.
