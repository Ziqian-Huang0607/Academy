## 6.7 Many-Electron Atoms

**Orbitals and Their Energy:**

- One-electron atoms:
  - All subshells with the same principal quantum number are degenerate
    - Degenerate = same energy for every electron within that subshell
- Many-electron atom:
  - Contains electron-electron repulsion = different energies
    - Energy order: Typically, ns<np<nd<nf

Note: Exceptions exist, e.g., 4s is lower in energy than 3d for transition metals.

  - Yet orbitals within the same subshell are degenerate
    - E.g. ${P}_{x}={P}_{y}={P}_{z}$
  - The energy of different principal levels may overlap.
    - E.g. Energy for 4s < 3d

**Aufbau Principle**

- Electrons occupy the orbital of the lowest energy first
- Orbitals of the same sublevel always have the same energy
- On the same principal energy level: s<p<d<f
- 1s<2s<2p<3s<3p<4s<3d<4p<5s<4d<5p<6s<4f<5d<6p<7s>5f<6d<7p

**Pauli Exclusion Principle:**

- An atomic orbital can hold a maximum of two electrons and they must have the opposite spin
  - Only when two electrons of opposite spin occupy an electron, it is paired
- Spin is a property of electrons
  - Spin clockwise/counterclockwise, the arrow pointing up is clockwise, pointing down is counterclockwise.

**6.8+6.9 Electron Configurations and the Periodic Table:**

**Orbital Diagram:**

- Box: one orbital
- Half Arrow: one electron
- Direction: the relative spin of the electron

**Electron Configuration:**

$$1{s}^{2}2{s}^{1}$$

- Coefficient: energy level
- Letter: type of orbital
- Superscript: number of electrons in that sublevel/subshell

**Hund’s Rule:**

- For degenerate orbitals, electrons will occupy empty orbitals with parallel spins before pairing up in the same orbital
- This meant that you fill out all the orbitals with arrows pointing in the same direction (or the maximum number of orbitals you may fill) before you start pairing them as two electrons in one orbital
- Orbitals are filled in order of increasing energy
- A maximum of two electrons are in each orbital

**Abbreviated Electron Configurations:**

- Aka: Condensed electron Configurations / Noble gas notation
- To substitute the core electrons with the previous noble gas (Or He as an exception) presented
- Represented in its chemical symbol in brackets
- E.g.: C: $1{s}^{2}2{s}^{2}2{p}^{4}$ can be written in:
  - $\left[ He \right] 2{s}^{2}2{p}^{4}$, as He is the previous noble gas while $2{s}^{2}2{p}^{4}$ are retained. *Even if the current element is a noble gas, you should still chose the previous noble gas to replace its core electrons. Eg. Ne=$\left[ He \right] 2{s}^{2}2{p}^{6}$

**Valence Electrons:**

- Core electrons: Inner Shell Electrons
  - This is basically the electron configuration for the noble gas core
  - E.g. $1{s}^{2}$ in C
- Outer shell electrons: electrons after the noble gas core
  - E.g. $2{s}^{2}2{p}^{4}$ in C
- Valence Electrons: Electrons responsible for chemical bonding and chemical behavior
  - For elements with an atomic number of 30 or less, the valence electrons are generally those in the outermost shell. (Note: for transition metals like Zn (atomic number 30), the d-electrons may also be considered valence electrons depending on context)
    - E.g. $2{s}^{2}2{p}^{4}$ in C
  - For transition elements:
    - Usually, it only includes the outermost electrons (in the biggest shell)
    - E.g. Cu = [Ar] $4{s}^{1} 3{d}^{10}$
      - Because $4{s}^{1}$ it is located in the outermost shell, it is the valence electron for this element
    - This rule will be more complicated when encountering deeper chemistry, but remember it like this just now

**Tips in Writing the Electron configuration of the element:**

- Write down [Noble Gas] ns np
- Add $(n-2){f}^{14}$if it is placed after the f block
- Add $(n-1)$ ${d}^{10}$ if the element is placed after the d block

**Tips when given the electron configuration**

- When given the full configuration, count up the electrons and locate the element to its atomic number (when it is a neutral atom)
- When given a condensed configuration, first locate the noble gas, and then add up the number of electrons. Then with the number of electrons, count up the same number after the noble gas.

**Electron Configurations of the Excited State:**

- Ground State: the most stable organization of electrons in its lowest possible energy
  - E.g. F : $1{s}^{2} 2{s}^{2}2{p}^{5}$
- Excited State: shows one or more electrons in a higher energy level
  - E.g. F : $1{s}^{2} 2{s}^{2}2{p}^{4} 3{s}^{1}$
- Tips for identifying the excited state:
- Make sure that the number of electrons corresponds to the atomic number of the element
- Remove the answer choice of ground choice
- Make sure that all the orbitals are correctly filled

**Electron Configuration for Ions**

- Atoms gain/lose electrons to achieve a stable noble gas configuration
  - usually an octet
- Metal Elements tend to lose electrons -> Form Cations
  - E.g. ${Mg}^{2+ }=\left[ Ne \right]$
- Non-metal elements tend to gain electrons -> Form Anions
  - E.g. ${Cl}^{- }=\left[ Ar \right]$
- Transition metals will lose outmost shell electron first, then lose the inner ones
  - E.g. ${Fe}^{2+ }=\left[ Ar \right]3{d}^{6}$

**Exceptional Electron Configurations**

- Cr (24) -> expected -> $\left[ Ar \right]4{s}^{2} 3{d}^{4}$
  - Actual -> $\left[ Ar \right]4{s}^{1} 3{d}^{5}$
- Mo (42) -> expected -> $\left[ Kr \right]5{s}^{2} 4{d}^{4}$
  - Actual ->$\left[ Kr \right]5{s}^{1} 4{d}^{5}$
- Ru (44) -> expected -> $\left[ Kr \right]5{s}^{2} 4{d}^{6}$
  - Actual -> $\left[ Kr \right]5{s}^{1} 4{d}^{7}$
- Cu (29) -> expected -> $\left[ Ar \right]4{s}^{2} 3{d}^{9}$
  - Actual -> $\left[ Ar \right]4{s}^{1} 3{d}^{10}$
- Ag (47) -> expected -> $\left[ Kr \right]5{s}^{2} 4{d}^{9}$
  - Actual ->$\left[ Kr \right]5{s}^{1} 4{d}^{10}$
- Au (79) -> expected -> $\left[ Xe \right]6{s}^{2} 4{f}^{14}5{d}^{9}$
  - Actual -> $\left[ Xe \right]6{s}^{1} 4{f}^{14}5{d}^{10}$
- Pd (46) -> expected -> $\left[ Kr \right]5{s}^{2}4{d}^{8}$
  - Actual -> $\left[ Kr \right]4{d}^{10}$
- Nb (48) ->expected -> $\left[ Kr \right]5{s}^{2} 4{d}^{3}$
  - Actual -> $\left[ Kr \right]5{s}^{1} 4{d}^{4}$
- General rules for the patterns:
  - When encountering situations of near half-filled/filled configurations
    - Move one s orbital electron to the higher energy orbital
    - An exception occurs in Pd, where both electrons in the s orbital would move to higher-energy levels.

**Electron Configuration and Periodic Table:**

- S block + p block = main group elements / representative elements
- D block = transition elements
- F block = inner transition elements
  - Aka : Lanthanides (4f) /actinides (5f)

- **Accuracy and precision**

Accepted value: the “true” value of the measurement

**Accuracy** of a measurement is an expression of **how close the measured value is to the accepted value.**

**Precision** is a set of measurements refers to how closely the individual measurements agree with one another. The precision is a measure of the **repeatability** of a result.

For individual measurement, the more significant figures are there, the more precise. It’s determined by the instrument you use.

For series of measurements, the closer they come to each other, the more precise.

**4.Error and uncertainty**

**Error**

Error = experimental value – accepted value

Error can be a negative value

**Systematic error**

Poor accuracy in measurements is usually associated with a systematic error.

Systematic errors are **always biased in the same direction**.

common sources:

zero error, badly made instruments, improper procedures or theories...

Systematic errors **cannot be reduced by repetition.**

**Random uncertainty**

**Poor precision in measurements is associated with random uncertainty.**

Error associated with estimating the last digit of a reading is called random uncertainty. Usually caused by instrument limits.

Can sometimes be higher than true value sometimes lower.

**Repeating the measurement** **for multiple** **times and averaging the results reduces the effect of random uncertainty.**

For the instrument with a **scale,** the uncertainty equal to half of the scale graduations. (Ruler, thermometer…)

Eg. The uncertainty of a 20cm ruler is 0.05cm

For an instrument with a **digital display,** the uncertainty is ±1 in the last decimal place of the reading, or in other words, the least count.

e.g. The measurement should be reported as 12.34±0.01g

For some **glassware**, the uncertainty will be labeled on it

**Absolute uncertainty**

Keep only 1 sf for abs uncertainty.

eg. 1.00 ±0.01g the abs uncertainty is 0.01

**Percentage Uncertainty** :

Percentage Uncertainty has no units

percentage uncertainty=abs uncertainty/true value
