# S2M-3 Part 3: Naming of Ions and Compounds

> From the Grade 9 Resource Department's Semester 2 Midterm Chemistry S+ review guide (PA). Writers: Justin Lee 9-4. Editor: Justin Lee 9-4. Range: 7.4-8.7. Student-made reference material: where it differs from class, follow class.

**Monatomic Ions**

**Cations**

Element Name + “ion”

- Ex: Sodium Ion, Potassium Ion, Magnesium Ion

Transition Metal with mutliple charges

Element name + “(roman numeral)” + “ion”

- Ex: Iron (II) Ion, Manganese (IV) Ion

**Anions**

Root + “ide”

- Ex: Chloride, Fluoride

**Polyatomic Ions**

**Ionic Compounds**

**General Idea**: name the cation first, then the anion

- NO prefixes (mono-, di-, tri- etc,)

**1. Metal + Nonmetal**

- (Cation) + (Anion+ide)

Examples:

- NaCl = sodium chloride
- MgO = magnesium oxide
- CuO = copper(II) oxide
- PbS₂ = lead(IV) sulfide

**2. Ionic Compounds with Polyatomic Ions**

- Keep the full name of the polyatomic ion exactly as it is, don’t add “ide”

Examples:

- NaNO₃ = sodium nitrate
- Ca(OH)₂ = calcium hydroxide
- CuCO₃ = copper(II) carbonate
- KMnO₄ = potassium permanganate

**Molecular Compounds**

  - Name the first element using its full name.
  - Name the second element with an -ide ending.
  - Use prefixes to show the number of each atom
    - If the number of the first element is 1, omit “mono-“
      - Ex: CO2 “carbon dioxide” not “monocarbon dioxide”
    - If the prefix ends with a vowel and the element starts with a vowel, drop the vowel for pronunciation
      - pentoxide (not pentaoxide), monoxide (not monooxide)
