## 3.1 Linear Inequalities; Absolute Value

Important Notations

- (1,5) →1<x<5
- [0,4] → 0≤x≤4
- (1,∞) → x>1
- A solid dot → an endpoint is included in the graph
- An open dot → an endpoint is not included in the graph

Absolute value of a number x can be interpreted geometrically as the distance from x to zero in either direction on the number line

In the same sense, |x-k| is interpreted as the distance from x to k in either direction of the number line

## 3.2 Polynomial Inequalities in One Variable

Methods to solve polynomial inequalities:

- Use a sign graph of P(x)
  - Can be used to solve inequalities involving functions of the form P(x)/Q(x) where P(x) and Q(x) are polynomials
- Analyze the graph of P(x)
  - P(x)<0 when graph is below the x-axis
  - P(x)>0 when graph is above the x-axis

**not all polynomials change sign at a zero**

**when solving polynomial inequalities of the form P(x)/Q(x), values of x that make Q(x)=0 are NEVER solutions**
