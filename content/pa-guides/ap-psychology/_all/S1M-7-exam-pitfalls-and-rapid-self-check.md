## Appendix A — Consolidated Exam Pitfalls

The traps below are the ones most likely to cost points. Each is phrased the way you should remember it for the exam.

| **Topic** | **The trap** |
|---|---|
| Random sampling | Write "equal chance," not just "random". |
| Correlation coefficient | Sign = direction only, NOT the slope (range −1.00 to +1.00). |
| Illusory correlation | Not the same as lurking variables or "correlation ≠ causation" — three separate concepts. |
| p-value | p < 0.05 AND p = 0.05 both mean "no difference" in AP Psychology. |
| Significance | Statistical ≠ practical significance — add effect size. |
| Skew | Look at the TAIL; the mean is highest in positive (right) skew. |
| Nervous system terms | CNS = tracts & nuclei; PNS = nerves & ganglia. |
| Myelin | CNS myelin = glial cell (oligodendrocyte), NOT Schwann cell. |
| Neurotransmitters | They BIND receptors — they do NOT enter the post-synaptic neuron. |
| Adrenaline | In a question, adrenaline/noradrenaline = the HORMONE; norepinephrine = neurotransmitter. |
| Brainstem | Medulla + pons + midbrain. |
| Cortex vs. cerebrum | Cortex = outer layer OF the cerebrum; cerebrum = the whole structure. |
| "50% genetic" | Refers to individual differences, not your trait. |
| Bimodal | Two peaks (textbook concept, may not be covered in class). |
| Standard deviation | AVERAGE distance of all data points from the mean. |
| Reliability | Consistently replicated — memorize it; the name misleads. |
| Consent | Informed consent → informed ASSENT for minors. |
| MDMA | Appears under BOTH stimulants and hallucinogens. |

## Appendix B — Rapid Self-Check

| **Question** | **Answer** |
|---|---|
| Stage with sleep spindles? | NREM-2 |
| Sense that skips the thalamus? | Smell |
| "Gorilla" experiment? | Inattentional blindness |
| Weber's Law = constant ____? | percentage |
| Sudden "Aha!"? | Insight |
| Updating a schema itself? | Accommodation |
| Blindsight patient walking the hallway? | Eyes work, awareness blind (dual processing) |
| Brain wave of deep sleep? | Delta |
| Extra REM after deprivation? | REM rebound |
| Rubbing an injury hurts less? | Gate-control theory |
| Seeing a green after-image? | Opponent-process theory |
| High pitches? Low pitches? | Place theory · Frequency theory |
| Lights blinking in sequence? | Phi phenomenon |
| Movies / animation? | Stroboscopic movement |
| Range of the correlation coefficient? | −1.00 to +1.00 |
