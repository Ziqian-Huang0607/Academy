**Tabular Display:**

Frequency distribution: A tabular summary of data showing the number (frequency) of observations in each of several nonoverlapping categories or classes.

Three steps to define the classes:

- **Determine the number of** **nonoverlapping classes**
- Use enough classes to show the variation in the data, but not so many classes that some contain only a few data items
- **Determine the width of each class:**

$$Ap\text{ proximate } \text{ class } \text{ width }= \frac{\text{ Largest } \text{ data } \text{ value }-\text{ Smallest } \text{ data } \text{ value }}{\text{ Number } of \text{ classes }}$$

- **Determine the class limits**
- must be chosen so that each data item belongs to one and only one class
- Lower class: smallest possible data value assigned to the class
- Upper class: largest possible data value assigned to the class

**Numerical values:**

Five-Number Summary:

- Minimum, Maximum, Median, First Quartile (Q1), Third Quartile (Q3)

**Definition:**

- Minimum: Smallest observations in a set
- Maximum: Largest observations in a set
- Mean: average of a set of observations
- Median: the value in the middle when the data are arranged in ascending order (smallest value to largest value) When even number of observations, take the average of the values for the middle two observations
- First Quartile (Q1): the median of the data below the overall median (1/4)
- Third Quartile (Q3): the median of the data above the overall median (3/4)
- Range: difference between the maximum and minimum values
- Interquartile Range: difference between First Quartile (Q1) and Third Quartile (Q3)
- Variance: average of the squared deviations
- Deviation about the mean: difference between each observation and the mean

**Describing and comparing distributions:**

- Shape: Physical appearance of the distributions
- Center: center of the distribution
- Spread: spread along with its center

**1-1** **Points and Lines**

**Distance Formula:**

$$d= \sqrt{{{(x}_{1}- {x}_{2})}^{2}+ {({y}_{1}- {y}_{2})}^{2}}$$

**Midpoint Formula:**

$$M= \left( \frac{{x}_{1}+ {x}_{2}}{2},\frac{{y}_{1}+ {y}_{2}}{2} \right)$$

- x-intercepts: point where a graph crosses the x-axis
- y-intercepts: point where a graph crosses the y-axis

**General form** **of a linear equation:**

$$Ax+By+C=0$$

- When A = 0, the line is horizontal
- When B = 0, the line is vertical
- When C = 0, the line passes through the origin

**Intersection between two lines means:**

- One intersection: one solution
- Parallel: No solution
- Coincide: Infinite many solutions

**1-2 Slope of Lines**

**Slope:**

$$\text{ Slope } m= \frac{\text{ Change } in y}{\text{ Change } in x}= \frac{{y}_{2}-{y}_{1}}{{x}_{2}-{x}_{1}}$$

- Horizontal lines have slope of 0
- Vertical lines have no slope
- When slope is positive, the line rises to the right; The greater the slope, the steeper the line rises.
- When slope is negative, the line falls to the right; The greater the absolute value of the slope, the steeper the line falls.
- Two nonvertical lines are signed as //, when they have the same slope
- Two nonvertical lines are signed as ⊥, if and only if m1 * m2 = -1 (Negative Reciprocals)

**1-7 Quadratic Functions and Their Graphs**

**Quadratic function:** (a$\ne 0)$: $f(x)=a{x}^{2}+bx+c$

Axis of symmetry: $A.O.S= -\frac{b}{2a}$

Vertex: $(-\frac{b}{2a} , f\left( -\frac{b}{2a} \right))$

x-intercepts are also called the **real zeros** of a function

Solving for the roots of quadratic function (a$\ne 0)$: $x=\frac{-b\pm \sqrt{{b}^{2}-4ac}}{2a}$

- $({b}^{2}-4ac)$ > 0 there are two x-intercepts
- $({b}^{2}-4ac)$ = 0 there is one x-intercept
- $({b}^{2}-4ac)$< 0 there are no x-intercepts

**Value of a:**

- Absolute Value of a determines the dilation of the parabola
- a > 0, the vertex is minimum open upward
- a < 0, the vertex is maximum open downward
