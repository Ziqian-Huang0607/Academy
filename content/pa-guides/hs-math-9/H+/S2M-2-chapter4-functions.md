**4.1Functions**

- Def: **-**A **function** is a correspondence or rule that assigns to every element in a set D exactly one element in a set R. (there should only be 1 intersection when you draw a vertical line)

**-** The set D is called the **domain** of the function; the set R is called the **range**.

- ceiling and floor

⌊x⌋ gets the closest integer smaller than x

⌈x⌉ gets the closest integer greater than x

## 4.4 Periodic functions, stretching and translating graphs

1.def:

- translate upwards ->f(x)->f(x)+a

downwards-> f(x)->f(x)-a

left->f(x)->f(x+a)

right->f(x)->f(x-a)

stretch vertically --> f(x) -> a × f(x) (a>1)

stretch horizontally --> f(x) -> f(a*x) (0<a<1)

shrink vertically --> f(x) -> a × f(x) (0<a<1)

shrink horizontally --> f(x) -> f(a*x) (a>1)

*when doing this, the coefficient for x must be 1

eg. transform y=f(x) to y=-2f(3x+3) -5
