## 2.3 Special triangles

- Corollary: a statement that follows immediately from a theorem
- Corollary to theorem 4-3: if a triangle is equilateral, then the triangle is equiangular
- Corollary to theorem 4-4: if a triangle is equiangular, then the triangle is equilateral

## 2.4         Inequalities in Triangles

- Comparison property of inequality: if a = b + c and c > 0, then a > b
- Corollary to the triangle exterior angle theorem: the measure of exterior angle is greater than each of the other two interior angles

## 2.5         Centers in Triangles

- When three or more lines intersect in one point, they are concurrent
- The point at which they intersect is the point of concurrency
- the point of concurrency of the perpendicular bisectors of a triangle is the circumcenter of the triangle
- the point of concurrency of the angle bisectors of a triangle is the incenter of the triangle
- median of a triangle is a segment whose endpoints are a vertex and the midpoint of the opposite sides
- altitude of a triangle is the perpendicular segment from a vertex to the line containing the opposite sides
- lines containing the altitudes of a triangle are concurrent at the orthocenter of the triangle

- the distance from a point to a line is the length of the perpendicular segment from the point to the line

Postulates and Theorems:

Postulate 1-1: through any two points there is exactly one line

Postulate 1-2: if two lines intersect, then they intersect in exactly one point Postulate 1-3: if two plains intersect, then they intersect in exactly one line Postulate 1-4: through any three noncolinear points there is exactly one plane Ruler postulate: the points of a line can be put into one-to-one correspondence with the real numbers so that the distance between any two points is the abs. of the difference of the corresponding numbers

Segment addition postulate: if A, B, and C are collinear points and B is between A and C, then AB + BC = AC

Angle addition postulate: if B is in the interior of ∠AOC, then m∠AOB + m∠BOC = m∠AOC

Properties of equality:

Addition: if a = b, then a + c = b + c

Subtraction: if a = b, then a – c = b – c

Multiplication: if a = b, then ac = bc

Division: if a = b, and c is not 0, then a/c = b/c

Reflexive: a = a

Symmetric: if a = b, then b = a

Transitive: if a = b and b = c, then a = c

Substitution: if a = b, then b can replace a in any expression

Distributive: a(b + c) = ab + ac

Properties of congruence:

Reflexive: AB = BA, ∠A = ∠A

Symmetric: if AB = CD, then CD = AB, if ∠A = ∠B, then ∠B = ∠A

Transitive: if AB = CD, CD = EF, the AB = EF, if ∠A = ∠B and ∠B = ∠C, then ∠A = ∠C Vertical angle theorem: vertical angles are congruent

Congruent supplement theorem: if two angles are supplements of the same angle, then they are congruent

Congruent complement theorem: if two angles are complements of the same angle, then they are congruent

Theorem 2-4: all right angles are congruent

Theorem 2-5: if two angles are congruent and supplementary, then each is 90° Corresponding angles postulate: if transversal intersects parallel lines, then corresponding angles are congruent

Alternate interior angles theorem (+converse): if transversal intersects parallel lines, then alternate interior angles are congruent

Same-side interior angles theorem (+converse): if transversal intersects parallel lines, then same-side interior angles are supplementary

Alternate exterior angles theorem (+converse): if transversal intersects parallel lines, then alternate exterior angles are congruent

Same-side exterior angles theorem (+converse): if transversal intersects parallel lines, then same-side exterior angles are supplementary

Theorem 3-9: if two lines are parallel to the same line, then they are parallel Theorem 3-10: in a plane, if two lines are perpendicular to the same line, then they are parallel

Theorem 3-11: in a plane, if a line is perpendicular to one of two parallel lines, then it is perpendicular to the other

Triangle angle-sum theorem: the sum of the measures of the angles of a triangle is 180o Triangle exterior angle theorem: measure of exterior angle of a triangle equals to the sum of other two interior angles

Theorem 4-1: if two angles of two triangles are congruent, then the third angle are congruent

Isosceles triangle theorem: if two sides of a triangle are congruent, then the opposing angles are congruent

Perpendicular bisector theorem (+converse): if a point is on the perpendicular bisector of a segment, then it is equidistant from the endpoints of the segment

Angle bisector theorem (+converse): if a point is on the bisector of an angle, then the point is equidistant from the sides of the angle
