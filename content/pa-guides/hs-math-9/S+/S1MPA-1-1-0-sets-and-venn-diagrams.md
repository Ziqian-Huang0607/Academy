Sets:

set: a well-defined collection of distinct number or objects

- each element is called an element or member of the set

Properties:

1.An element is either in the set or not in the set.

2.The elements in the set are distinct. An element can appear only once.

3.There is no fixed order when elements in the set are described.

4.Two sets are equal if they contain exactly the same elements.

Important Number Sets:

1.N (natural numbers)

2.Z (integers)

3.Z+ or N* (positive integers)

4.Q (rational numbers)

5.R (real numbers)

Representation:

1.Listing: Use {} to list all of the elements in the set (mainly used for finite sets). All elements are separated by “,”. “...” can be used for sets that has a large number of elements which follow the same pattern.

2.Describing: Use certain conditions or rule to express the elements.

Number of Subsets of a Set:

2n (n is the number of elements in the set)

Relationship Between Sets:

∈: “is an element of”

∉: “is not an element of”

⊆: Given sets A and B. If x∈A and x∈B, then A is the subset of B.

- any subset is the subset of itself

- A = B if and only if A⊆B and B⊆A

⊂: Given sets A and B. If A⊆B, x∈B and x∉A, then A is the proper subset of B.

A - B: elements that are in A but not in B.

Empty Set:

symbol: ∅

- a set that contains no elements

- subset of any set

- {∅} means a set with one element: empty set

Venn Diagrams:

Venn diagram: consists of a universal set (U) represented by a rectangle, and subsets within it that are generally represented by circles

Relationships in Venn Diagrams:

∩: The intersection of two sets A and B is the set of elements both in A and B.

- A and B are mutually exclusive when A∩B=∅

1.A∩B = B∩A

2.A∩A = A

3.A∩∅ = ∅

4.A∩B⊆A, A∩B⊆B

5.A∩B = A if and only if A⊆B

6.(A∩B)∩C = A∩(B∩C)

∪ : The union of two sets A and B is the set of elements either in A or B.

1.A∪B = B∪A

2.A∪A = A

3.A∪0 = A

4.A⊆A∪B, B⊆A∪B

5.A∪B = B if and only if A⊆B

6.(A∪B)∪C = A∪(B∪C)

A’: The complement of set A is the set of all elements in U but are not elements of A.

1.(A’)’ = A

2.U’ = ∅, ∅’ = U

3.A’∩A = ∅, A’∪A = U

4.A⊆B if and only if B’∩A = ∅, A’∪B = U

De Morgan’s Law:

(A∪B)’ = A’∩B’, (A∩B)’ = A’∪B’

Principle of Inclusion and Exclusion:

n(A∪B) = n(A) + n(B) - n(A∩B)

n(A∪B∪C) = n(A) + n(B) + n(C) - n(A∩B) - n(A∩C) - n(B∩C) + n(A∩B∩C)

1.Patterns and Inductive Reasoning

inductive reasoning: a method used to tell what the next terms on the sequence will be based on patterns observed

conjecture: a conclusion reached using inductive reasoning

counterexample: an example for which the conjecture is wrong

## 2.1 Conditional Statements

conditional: If p, then q.

converse: If q, then p.

## 2.2 Biconditionals and Definitions

Biconditionals:

biconditional: P if and only if q.

- nly when the conditional and its converse are both true

Definitions:

1.Uses clearly-understood terms

2.Precise

3.Reversible

## 5.4 Inverses, Contrapositives, and Indirect Reasoning

Inverses and Contrapositives:

negation: a statement that has the opposite truth value

symbol: ~

inverse: If not p, then not q.

- same truth value as converse

contrapositive: If not q, then not p.

- same truth value as conditional

Indirect Proof:

Step 1: State an assumption that is opposite of what you want to prove.

Step 2: Show that this assumption leads to a contradiction.

Step 3: Conclude that this assumption must be false, and that what you want to prove must be true.

## 2.3 Deductive Reasoning

deductive reasoning: the process of reasoning logically from given statements to a conclusion

Law of Detachment (L.O.D): If P→Q is true and P is true, then Q is true.

Law of Syllogism (L.O.S): If P→Q is true and Q→R is true, then P→R is true.
